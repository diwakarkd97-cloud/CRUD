# JavaScript CRUD Operations with Fetch API

A lightweight, vanilla JavaScript project demonstrating how to execute full CRUD (Create, Read, Update, Delete) operations interacting with a RESTful API. This project uses the modern ES6 `async/await` syntax alongside the native `fetch` API to handle asynchronous network requests.

## Features

* **Create (POST):** Add new user records to the database.
* **Read (GET):** Retrieve specific user data by their unique ID.
* **Update (PUT):** Modify existing user records based on their ID.
* **Delete (DELETE):** Remove user records from the database.
* **Asynchronous Handling:** Built entirely with `async/await` for clean, readable promise resolution.

## Technologies Used

* **JavaScript (ES6+)**
* **Fetch API**
* **MockAPI** (for the backend REST endpoint)

## Setup and Execution

1. Clone this repository or download the files.
2. Link the JavaScript file to an `index.html` file (e.g., `<script src="javascript.js"></script>`).
3. Open the `index.html` file in any modern web browser.
4. Open the Developer Tools (Right-click -> Inspect -> Console) to view the API response logs.

Alternatively, if you have Node.js installed, you can run the file directly from your terminal:
```bash
node javascript.js
